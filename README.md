Customer Shopping Behavior Data Analytics
Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, customer preferences, sales performance, and revenue trends.

The project uses a customer shopping behavior dataset containing 3,900 customer records and 18 different attributes related to customer purchases.

The analysis is performed using PostgreSQL, SQL, Google Colab, Python, and Power BI.

Dataset Description

The dataset contains information about customers, their purchases, products, payment methods, discounts, subscriptions, shipping methods, and purchase frequency.

Dataset Columns
Column	Description
Customer ID	Unique identification number assigned to each customer
Age	Age of the customer
Gender	Gender of the customer
Item Purchased	Name of the product purchased
Category	Product category
Purchase Amount	Amount spent by the customer
Location	Customer location
Size	Size of the purchased product
Color	Color of the purchased product
Season	Season in which the purchase was made
Review Rating	Rating given by the customer
Subscription Status	Indicates whether the customer has a subscription
Shipping Type	Type of shipping selected by the customer
Discount Applied	Indicates whether a discount was applied
Promo Code Used	Indicates whether a promotional code was used
Previous Purchases	Number of previous purchases made by the customer
Payment Method	Payment method used for the purchase
Frequency of Purchases	How frequently the customer makes purchases

Project Workflow

The project follows these steps:

1. Data Collection

The customer shopping behavior dataset is collected in CSV format.

2. Data Storage

The dataset is imported into PostgreSQL and stored in the customer_behavior database.

3. Data Cleaning

The dataset is checked for missing values, duplicate records, incorrect data types, and inconsistent values.

4. SQL Analysis

SQL queries are used to answer important business questions related to customers, products, revenue, discounts, subscriptions, and purchasing behavior.

5. Python Analysis

Google Colab and Python are used for exploratory data analysis and visualization.

6. Power BI Dashboard

The cleaned and analyzed data is connected to Power BI to create an interactive dashboard.

7. Business Insights

The final results are analyzed to identify useful business trends and recommendations.
